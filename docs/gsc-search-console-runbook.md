# Google Search Console runbook (hyperlocal realtor sites)

Use this checklist after deploy and monthly. For multi-domain launches, also see [Fleet rollout checklist](./fleet-rollout-checklist.md).

## One-time setup

1. **Property type** — Add a URL-prefix property that matches the **canonical** host exactly.
   - **Sunstone Las Vegas Homes:** `https://www.sunstonelasvegashomes.com/` (`SITE.website` in [`src/config.ts`](../src/config.ts)).
   - Apex `sunstonelasvegashomes.com` **301s to www** via [`vercel.json`](../vercel.json). Use the **www** URL-prefix property in GSC (not apex-only).
2. **Ownership** — Complete verification (DNS TXT recommended for durability, or HTML meta tag).
   - Meta tag: set `NEXT_PUBLIC_GOOGLE_SITE_VERIFICATION` or `PUBLIC_GOOGLE_SITE_VERIFICATION` in Vercel → rendered in [`src/app/layout.tsx`](../src/app/layout.tsx).
3. **Sitemap** — Submit **`https://www.sunstonelasvegashomes.com/sitemap.xml`** (Next.js App Router convention). Confirm **Success** under Sitemaps.
4. **Robots** — Confirm `https://www.sunstonelasvegashomes.com/robots.txt` lists `Sitemap: https://www.sunstonelasvegashomes.com/sitemap.xml`. Generated by [`src/app/robots.ts`](../src/app/robots.ts).

## Post-migration note (Astro → Next.js)

| Before (Astro) | After (Next.js) |
| -------------- | --------------- |
| `/sitemap-index.xml` | `/sitemap.xml` |
| `Layout.astro` meta verification | `layout.tsx` `metadata.verification.google` |
| `/_astro/` in robots Allow | Not applicable — remove any old GSC “blocked asset” notes for `/_astro/` |

Resubmit the new sitemap URL after the Next.js deploy reaches production.

## After each deploy (high priority URLs)

1. **URL Inspection** — Test homepage and money pages:
   - `/`
   - `/buyers/`
   - `/faq/`
   - `/contact/`
   - `/sellers/`
   - `/sunstone/`
   - `/about/`
2. **Request indexing** — Only for **new or materially changed** URLs; avoid bulk requests.
3. **Rich Results Test** — Validate **FAQPage** on `/faq/` and `RealEstateAgent` JSON-LD (view source → `application/ld+json`).

## Monthly review

1. **Performance** → Pages: impressions/clicks; fix weak titles/descriptions.
2. **Page indexing** — Fix `noindex`, redirect chains, canonical mismatches.
3. **Core Web Vitals** — LCP/INP (images, RealScout embeds, fonts).
4. **Enhancements** — Structured data errors (FAQ, agent).

## Expectations

- **Discovered – currently not indexed** often reflects crawl priority—not always a bug if sitemap + canonical are correct.
- Reports can lag **days to weeks** after fixes.

## Related env (NAP + entity alignment)

Set `PUBLIC_SITE_*` / `NEXT_PUBLIC_SITE_*`, maps, reviews, and `PUBLIC_GOOGLE_BUSINESS_PROFILE_URL` so footer NAP, JSON-LD `sameAs`, and GBP stay aligned.
